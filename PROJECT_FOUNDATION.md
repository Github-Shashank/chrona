# Chrona Project Foundation

## 1. Introduction

Chrona is an adaptive desktop productivity assistant designed to intelligently manage tasks, deadlines, schedules, and workload planning through dynamic scheduling and conflict-aware task management.

Unlike traditional task managers, Chrona focuses on:

* adaptive scheduling,
* workload analysis,
* intelligent task chunking,
* conflict resolution,
* and continuous replanning.

Chrona is designed as a terminal-first productivity system with minimal UI and calendar-based visualization.

---

## 2. Vision

To create a production-grade personal productivity system capable of:

* dynamically organizing work,
* intelligently allocating time,
* reducing deadline stress,
* avoiding scheduling conflicts,
* and adapting to changing workloads automatically.

Chrona aims to function as an intelligent productivity operating layer rather than a static reminder application.

---

## 3. Core Principles

### Adaptive Scheduling

Schedules should continuously adapt based on:

* new tasks,
* workload changes,
* timetable updates,
* leave days,
* and missed deadlines.

### Conflict Awareness

Chrona should detect and resolve:

* time conflicts,
* workload overload,
* deadline risks,
* and scheduling inefficiencies.

### Minimal Interface

Chrona prioritizes:

* terminal-based interaction,
* lightweight design,
* fast workflows,
* and focused productivity.

### Production-Oriented Architecture

The system should be:

* modular,
* scalable,
* maintainable,
* and extensible.

---

## 4. Key Concepts

### Actual Deadline

The final real-world deadline after which the task loses practical value.

### Expected Deadline

An internal target completion deadline intended to reduce stress and provide scheduling buffer before the actual deadline.

### Dynamic Replanning

Schedules should automatically update whenever:

* new tasks are added,
* tasks are delayed,
* schedules change,
* or conflicts are detected.

---

## 5. MVP Scope

### Included

* Task creation and management
* Actual and expected deadlines
* Timetable management
* Free-time analysis
* Basic automatic scheduling
* Conflict detection
* Calendar visualization
* Notification system
* Terminal-based interaction

### Excluded

* Voice assistant
* AI agents
* Full natural language understanding
* Cloud synchronization
* Mobile application
* Autonomous system control

* Scheduler Engine

* Timetable Manager
* Notification System
* Calendar Visualization

* Storage Layer

---

## 7. Scheduling Philosophy

Chrona should prioritize:

1. Deadline safety
2. Workload balance
3. Conflict minimization
4. Consistent progress
5. Reduced last-minute pressure

Scheduling decisions should consider:

* available time,
* task complexity,
* estimated effort,
* task priority,
* and user timetable constraints.

---

## 8. Long-Term Goals

Future versions of Chrona may include:

* intelligent task estimation,
* adaptive workload learning,
* natural language input,
* automation systems,
* GitHub integration,
* study planning assistance,
* and predictive scheduling.

---

## 9. Development Philosophy

Chrona should evolve incrementally:

1. Strong deterministic systems first
2. Reliable scheduling logic
3. Stable modular architecture
4. Intelligent behavior later

The project prioritizes system quality and architecture over visual complexity.
